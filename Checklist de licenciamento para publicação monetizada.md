# Checklist de licenciamento para publicação monetizada

Este documento deve ser preenchido antes de publicar qualquer vídeo gerado no YouTube ou TikTok com monetização.

## Verificações obrigatórias

| Item | Pergunta | Estado inicial |
|---|---|---|
| Código | A licença do código permite uso comercial? | Pendente |
| Pesos | A licença de cada checkpoint permite uso comercial? | Pendente |
| Dependências | Cada componente auxiliar foi verificado separadamente? | Pendente |
| Entrada | Temos autorização para usar o vídeo e o áudio? | Pendente pelo operador |
| Saída | Os termos permitem monetizar o vídeo gerado? | Pendente |
| Serviço | Existe marca d'água, atribuição obrigatória ou limite comercial? | Pendente |

## Regra do projeto

Não considerar uma ferramenta comercialmente segura apenas porque o código é open source. A licença dos pesos treinados e das dependências pode ser diferente. Se houver divergência, ambiguidade ou ausência de licença, o uso para monetização fica bloqueado até esclarecimento formal.

## Wav2Lip

O Wav2Lip open source permanece restrito a validação interna neste projeto. O teste técnico não deve ser publicado ou monetizado sem autorização específica dos detentores dos direitos.

## MuseTalk

O código do MuseTalk declara MIT, mas o model card oficial e os pesos no Hugging Face exibem `creativeml-openrail-m` ao mesmo tempo em que o model card afirma uso comercial. Essa divergência permanece pendente de esclarecimento formal e impede sua aprovação automática para monetização.
